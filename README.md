# Labyrinth Game

A WPF implementation of the board game "The Amazing Labyrinth".

## Technologies

- C#
- .NET 8
- WPF
- MVVM
- Visual Studio

## Project Structure

- `Models` contains game data and rules.
- `ViewModels` contains presentation logic.
- `Views` contains WPF windows and controls.
- `Services` contains reusable application services.
- `Resources` contains images, music, and profile files.

## How to Run

1. Open the solution in Visual Studio.
2. Select the project `LabyrinthGame`.
3. Press `F5` or choose `Start Debugging`.

## Development

The project is developed step by step. Each logical change is saved in a separate Git commit.
